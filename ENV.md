# Переменные окружения (для ознакомления)

> Этот файл описывает конфигурацию словами вместо готового `.env`.
> Реальные значения (токены, ключи мерчанта) не входят в комплект.

Бот читает конфигурацию из переменных окружения (файл `.env` в корне).
Ниже — назначение каждой переменной:

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `ADMIN_IDS` | ID администраторов через запятую |
| `PLATEGA_MERCHANT_ID` | ID мерчанта платёжной системы Platega |
| `PLATEGA_SECRET` | Секретный ключ Platega (проверка вебхуков) |
| `PLATEGA_API_URL` | Endpoint создания транзакции Platega |
| `PLATEGA_PAYMENT_METHOD` | Код метода оплаты |
| `PLATEGA_CURRENCY` | Валюта (напр. RUB) |
| `WEBHOOK_URL` | Публичный URL для приёма вебхуков оплаты |
| `WEBHOOK_PORT` | Порт локального веб-сервера вебхуков |
| `DB_PATH` | Путь к файлу базы данных SQLite |
| `LOG_LEVEL` | Уровень логирования (info/debug/...) |
| `TOPUP_MIN` | Минимальная сумма пополнения |
| `PREMIUM_EMOJI_IDS` | ID премиум-эмодзи по ключам |
